# cordova-plugin-reteno

Reteno SDK for Cordova and Capacitor apps.

Version 2.2.1 includes Reteno Android SDK 2.10.2 and Reteno iOS SDK 2.7.4.

## Installation

```bash
npm install cordova-plugin-reteno
```
